# AZA UNIVERSE — responsive MVP

**AZA UNIVERSE** — адаптивдүү бир сайт: телефон экранында мобилдик интерфейс, ноутбук/компьютерде кеңири интерфейс автоматтык ачылат. Өзүнчө эки сайт керек эмес.

## Файлдар

- `index.html` — башкы бет, бөлүмдөр жана диалог терезелери
- `styles.css` — космостук неон-дизайн, desktop/tablet/mobile көрүнүштөрү жана анимациялар
- `app.js` — KG/RU которуу, 5 суроолук тесттер, реакция мини-оюну, AZA Studio шаблондору, бөлүшүү, издөө, статистика
- `assets/aza-emblem.svg` — AZA Universe эмблемасы
- `assets/flame.svg` — баштапкы жалын белгиси

## Азыр иштеген функциялар

- Экран өлчөмүнө жараша автоматтык адаптация жана мобилдик төмөнкү навигация
- Кыргызча/орусча интерфейс которгучу
- Жалпы билим, аниме, логика, авто жана мүнөз темаларындагы 5 суроолук тесттер
- Реакция мини-оюну жана эң жакшы убакытты сактоо
- Упайлар, өткөн тесттер, мыкты тест жыйынтыгы жана күнүмдүк прогресс
- `AZA Studio`: социалдык пост, никнейм жана видео идеясына шаблон түзүү
- Бөлүшүү, ички издөө, профилдик статистика терезеси
- Статистика `localStorage` аркылуу ошол браузерде сакталат

## Азырынча жок / маанилүү чектөөлөр

- **Жалпы онлайн рейтинг жок.** Бир нече адамдын упайын салыштыруу үчүн сервер жана маалымат базасы керек.
- **Чыныгы AI API туташкан эмес.** AZA Studio учурда шаблондук генератор; чыныгы AI үчүн API сервердик тарапка туташтырылышы керек. API ачкычын браузердин кодунда сактаба.
- Колдонуучунун каттоо эсеби, аккаунт синхрондоштуруу жана админ-панель жок.
- Азырынча демо-версия: дизайн жана негизги функциялар иштейт, бирок сервердик мүмкүнчүлүктөр кийинки этапта кошулат.

## Компьютерде локалдык текшерүү

`index.html` файлын браузерден ач. Интернет туташуусу жок болсо, Google Fonts жүктөлбөшү мүмкүн, бирок резервдик системалык шрифт колдонулат.

## Cloudflare Pages'ке жайгаштыруу

1. GitHub'да репозиторий түз.
2. ZIP'тин ичиндеги файлдарды репозиторийдин **тамыр папкасына** жүктө (`index.html` эң үстүңкү деңгээлде болушу керек).
3. Cloudflare Dashboard → Workers & Pages → Create application → Pages → Import an existing Git repository.
4. Production branch: `main`.
5. Build command: `exit 0`.
6. Build output directory: `.` (репозиторийдин тамыры).
7. Deploy бас. Сайт `*.pages.dev` доменинде ачылат.

Расмий нускама: https://developers.cloudflare.com/pages/framework-guides/deploy-anything/

## Кийинки этап

1. Тесттерди, оюндарды жана деңгээл системасын көбөйтүү.
2. Онлайн рейтинг үчүн сервер/API жана маалымат базасы кошуу.
3. Чыныгы AI функцияларды коопсуз сервердик API аркылуу кошуу.
4. Аккаунт, жетишкендиктер, күнүмдүк серия жана PWA орнотуу мүмкүнчүлүгүн кошуу.
